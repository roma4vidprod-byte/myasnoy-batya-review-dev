Безопасный анализ HAR

Файл анализируется только в вашем браузере. Он не отправляется на сервер и не сохраняется в Supabase.

Как получить HAR: Яндекс Бизнес → Отзывы → F12 → Network → обновить страницу → Export HAR. Перед экспортом желательно очистить список запросов и оставить только загрузку страницы отзывов.
