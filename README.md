# Мясной Батя — Review Activator DEV

Изолированный DEV-preview текущей версии `LOCAL DEMO v0.4 BRAND`.

## Scope

- Статический single-page demo: `index.html`.
- Данные хранятся только в `localStorage` браузера.
- Supabase, Business OS API, реальные базы, рекламные кабинеты и production-интеграции не подключены.
- QR в этой версии — визуальный preview; локальные ссылки с `#r=TOKEN` работают в браузере.

## Local run

Откройте `START_LOCAL_DEMO.bat` или запустите любой static HTTP server из корня проекта.

## Vercel

Проект подготовлен как статический Vercel project без build command и без environment variables. Deployment target — DEV/Preview only.
